# Standing Recall Test — Natural Standing Events (SRE-002)

SRE-002 asks what happens after a finalized decision legitimately relied on evidence or authority and that basis later **naturally** changes standing.

It adds no new OpenLine inference mechanism. The candidate mechanism is the frozen SRE-001 standing evaluator. The change from SRE-001 is the event substrate: eight real public lifecycle events instead of injected lifecycle events.

The frozen corpus contains 8 events, 24 scored target dispositions, and an even 12/12 split between `REOPEN` and `SURVIVE`. The event families are `CORRECT`, `REVOKE`, `SUPERSEDE`, and `EXPIRE`, two historical events per family.

The two comparison systems remain deliberately conservative about novelty. DGRR is represented by a node-support contract abstraction. MemoRepair receives a strong barrier-first repair contract with exact property-aware validation. Neither is author code.

Gold is frozen from disclosed public-record dispositions. It is not generated by OpenLine.

At installation the status is `NATURAL_CORPUS_READY_UNRUN`. No benchmark result is checked in. CI produces the first repository-visible score and independent replay artifact.

See `PROTOCOL.md` for the frozen test and `SOURCES.md` for source boundaries.
