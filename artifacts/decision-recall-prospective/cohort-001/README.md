# Cohort 001 empirical ledger

This directory begins empty by design. It is populated only by real accepted
repository decisions after the cohort-installation commit.

- `manifests/` — prospectively captured receiver-confirmed dependency records.
- `pre-trigger-records/` — conventional records built independently of manifests.
- `observations/` — bindings from one accepted decision to its manifest, record,
  and canonical subject change set.
- `exclusions/` — explicit classifications for post-activation commits that do not
  qualify as accepted consequential decisions.

The cohort setup commit does not count. Empty directories are represented in the
root-ready package by this README; data directories are created by the operator as
needed.
